# Penguin Keybinds

User-set keybinds will be added in the future (sooner rather than later, as I know this is an essential feature)
In the meantime, enjoy these keybinds:


| Keybind | Action | Applicable Tabs |
| -------- | -------- | ------------ |
| Ctrl + Drag (on BPM label) | Adjusts beatline position according to drag delta | Tempo Map
| Ctrl + Alt + Drag (on BPM label) | Adjusts beatline position while anchoring the next event | Tempo Map
| Double Left Click (on any label) | Enables editing of BPM/TS event via manual typing | Tempo Map
| Scroll wheel | Adjusts song time according to scroll change | All |
| Ctrl + Shift + Select | Select all events between two points in a lane | All |
| Shift + Select | Select all events between two points | All |
| Middle Mouse Button + move | Same as scroll wheel, but faster | All |
| Delete/Backspace | Deletes objects in current selection | All |
| Spacebar | Play/pause audio | All |
| Click (in edit mode) | Adds event at previewed position | All |
| Ctrl + C | Copy selection | All |
| Ctrl + V | Paste selection | All |
| Ctrl + X | Cut selection | All |
| Ctrl + A | Select all | All | 
| Q | Decrease step | All |
| W | Increase step | All |
| Ctrl + Q | Decrease step x1 | All |
| Ctrl + W | Increase step x1 | All |
| Ctrl + Z | Undo | All |
| Ctrl + Shift + Z / Ctrl + Y | Redo | All |
| Ctrl + S | Save | All |
| Ctrl + N | New | All |
| Ctrl + Shift + S | Save as | All |
| Ctrl + O | Open | All |
| X | Set note default | Chart - Five Fret | 
| S | Set note forced strum | Chart - Five Fret |
| A / H | Set note forced HOPO | Chart - Five Fret |
| Z / T | Set note forced Tap | Chart - Five Fret |
| E | Toggle Extended Sustains | Applicable Charting Modes |
| = | Apply equal spacing to selection | Chart |
| 1 / 2 / 3 / 4 / 5 / 6 | Set selection to lane X | Chart |
| 0 / Numpad slash / Shift + C | Set sustains zero | Chart |
| 9 / Numpad star / C | Set sustains maxed | Chart |
| B | Toggle view mode | Chart |
| F / Mouse forward | Toggle edit mode | Chart |
| G / Mouse back | Toggle selection mode | Chart |
| Y | Toggle solo placement | Chart |
